# Field Input

> A flexible input component wrapper that supports text, number, date, and textareas, displaying labels, errors, and optional confidence badges in a consistent layout.

## Installation

```bash
npm install @cnma/react-ui
```

## Anatomy

```tsx
import { FieldInput } from "@cnma/react-ui";

<FieldInput 
  label="First Name" 
  value={name} 
  onChange={setName} 
  placeholder="Enter your first name" 
/>
```

## Props API Reference

### FieldInput

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | **Required** | The label for the input field. |
| `value` | `any` | **Required** | The current value of the input. |
| `onChange` | `(value: any) => void` | **Required** | Callback fired when the input value changes. |
| `type` | `'text' \| 'number' \| 'date' \| 'textarea' \| 'checkbox'` | `'text'` | The type of the input field. |
| `placeholder` | `string` | — | Placeholder text for the input. |
| `error` | `string` | — | Error message to display below the input. |
| `className` | `string` | — | Optional CSS class name for the wrapper. |
| `confidence` | `number` | — | Optional confidence score (0-1) to display a badge adjacent to the label. |
| `readOnly` | `boolean` | `false` | Whether the input is read-only. |

## Variants & Examples

### With Confidence and Errors
```tsx
import { FieldInput } from "@cnma/react-ui";

export default function FieldInputDemo() {
  return (
    <div className="max-w-sm space-y-4">
      <FieldInput
        label="Predicted Amount"
        type="number"
        value={500}
        onChange={() => {}}
        confidence={0.92}
      />
      <FieldInput
        label="Username"
        value=""
        onChange={() => {}}
        error="This field is required."
      />
    </div>
  );
}
```

## Accessibility
- Associates the `<Label>` visually, though ARIA linking might be necessary depending on the inner generic primitive.
- Errors are displayed clearly in semantic red text (`text-destructive`).

## Design Guidelines
- **Do** use `FieldInput` when you need a standardized vertical layout for label, input, and error messages.
- **Do** pass the `confidence` prop when the data was generated by AI or OCR.
