# Collapsible

> A single expandable/collapsible section for toggling content visibility.

## Installation

```bash
npm install @cnma/react-ui
```

## Anatomy

```tsx
<Collapsible>
  <CollapsibleTrigger>
    {/* Trigger element (e.g., Button) */}
  </CollapsibleTrigger>
  <CollapsibleContent>
    {/* Collapsible content area */}
  </CollapsibleContent>
</Collapsible>
```

## Props API Reference

### Collapsible
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `asChild` | `boolean` | `false` | Change the default rendered element for the one passed as a child. |
| `defaultOpen` | `boolean` | `false` | The open state of the collapsible when it is initially rendered. |
| `open` | `boolean` | — | The controlled open state of the collapsible. |
| `onOpenChange` | `(open: boolean) => void` | — | Event handler called when the open state of the collapsible changes. |
| `disabled` | `boolean` | `false` | When `true`, prevents the user from interacting with the collapsible. |
| `className` | `string` | — | Additional CSS classes for styling. |

### CollapsibleTrigger
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `asChild` | `boolean` | `false` | Change the default rendered element for the one passed as a child. |
| `className` | `string` | — | Additional CSS classes for styling. |

### CollapsibleContent
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `asChild` | `boolean` | `false` | Change the default rendered element for the one passed as a child. |
| `forceMount` | `boolean` | — | Used to force mounting when more control is needed. Useful when controlling animation with React animation libraries. |
| `className` | `string` | — | Additional CSS classes for styling. |


## Accessibility

- **Keyboard interactions:**
  - `Space` or `Enter`: When focus is on the `CollapsibleTrigger`, toggles the expanded/collapsed state.
- **ARIA roles:**
  - The `CollapsibleTrigger` has `aria-expanded` set to `true` or `false` indicating the state.
  - The `CollapsibleTrigger` has `aria-controls` referencing the `id` of the `CollapsibleContent`.
  - The `CollapsibleContent` is given a unique `id` generated by the system.

## Design Guidelines

### ✅ Do
- Use for supplementary content or settings that are secondary to the main task.
- Ensure the trigger clearly indicates its state (expanded or collapsed), usually via an icon like a chevron.

### ❌ Don't
- Don't use `Collapsible` if the content inside is the primary focus of the page.
- Don't nest collapsibles too deeply; it can cause navigation confusion.
- For multiple, coordinated collapsible sections, consider using an `Accordion` instead.
