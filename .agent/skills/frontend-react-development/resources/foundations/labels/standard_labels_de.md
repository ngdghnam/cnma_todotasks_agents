# Standardbezeichnungen

Dieses Dokument bietet eine umfassende Liste von Standardbezeichnungen, die über alle Applikationen hinweg verwendet werden sollen. Die Sicherstellung einer konsistenten Terminologie verbessert die Benutzerfreundlichkeit und Klarheit.

## Allgemeine Terminologie

Die folgende Tabelle definiert die bevorzugten Bezeichnungen für gängige Entitäten und Felder.

| Standardbezeichnung | Nicht verwenden (Beispiele) | Beschreibung                                                                 |
| :------------------ | :-------------------------- | :--------------------------------------------------------------------------- |
| **Lieferantenname** | Kreditor, Kreditor Name     | Der offizielle Name der Geschäftseinheit, die Waren oder Dienstleistungen liefert. |
